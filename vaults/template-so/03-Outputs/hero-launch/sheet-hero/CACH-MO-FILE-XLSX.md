# Cách mở & dùng `BoMau-DoiSoat-LaiThat-daSan.xlsx`

> **TL;DR:** File `.xlsx` này là **sản-phẩm THẬT, công-thức chạy sẵn** (6 tab). Mở bằng Excel, hoặc import vào Google Sheets là dùng ngay — không cần dựng từ CSV.

## Mở bằng Google Sheets (khuyến-nghị — vì SP định-vị là "Google Sheet")
1. Google Drive → **Mới → Google Trang tính → trống**.
2. **Tệp → Nhập (Import) → Tải lên** → chọn `BoMau-DoiSoat-LaiThat-daSan.xlsx`.
3. Chọn **"Thay thế bảng tính"** (hoặc "Chèn trang tính mới") → **Nhập dữ liệu**.
4. Công-thức (VLOOKUP/SUMIFS/IF) + định-dạng + tô-màu lãi âm giữ nguyên, tính tự-động.

## Mở bằng Excel
Nhấp đúp file — chạy ngay (Excel 2016+). Công-thức tự tính.

## Dùng
1. Tab **1. Cấu hình phí** → sửa % phí theo Kênh Người Bán THẬT của bạn (số đang điền là benchmark 2026).
2. Tab **2. Nhập đơn** → xoá dữ-liệu mẫu (DH001–DH008), nhập/dán đơn thật. Cột **Kênh** & **COD** chọn từ danh-sách sổ xuống.
3. Tab **4. Lãi thật** → tự ra lãi/lỗ + biên% từng đơn (lãi âm tô đỏ). *Thêm đơn ở tab 2 → kéo công-thức tab 4 xuống tương-ứng.*
4. Tab **3. Đối soát** → nhập "tiền sàn thực nhận" (cột vàng) để bắt lệch tiền về.
5. Tab **5. Dashboard** → tổng lãi theo kênh/SKU.

## Lưu ý (giữ đúng grounding)
- Thuế mặc-định **1,5%** (GTGT 1% + TNCN 0,5% — hàng-hóa, TT40/2021). **MẪU — cần kế-toán rà.**
- Mọi % phí sàn = **benchmark 2026, cần xác minh** theo tài-khoản thật.
- Dữ-liệu đơn trong file là **ví-dụ minh-hoạ** — xoá và nhập số thật.
- Bản-quyền: file chỉ dùng hàm/định-dạng bảng-tính chuẩn, **không asset bên thứ ba** → bán được, sạch quyền.
