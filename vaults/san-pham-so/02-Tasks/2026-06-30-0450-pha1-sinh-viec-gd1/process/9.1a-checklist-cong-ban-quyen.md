# 9.1a — Checklist Cổng Bản Quyền Hero (Pre-Release Gate)

> **TL;DR:** Mọi file sản phẩm số (kit/template) phải qua 5 cổng kiểm bản quyền trước khi phát hành. Fail bất kỳ 1 cổng → DỪNG, không phát hành cho đến khi khắc phục. Tài liệu này là MẪU — cần chuyên gia SHTT rà nếu có tình huống phức tạp.

---

## Nguyên tắc gốc

| Nguồn | Quy tắc cốt lõi |
|---|---|
| Luật SHTT VN (Luật 50/2005/QH11 + sửa đổi 2022) | Chỉ được bán nội dung do mình tạo hoặc có license hợp lệ thương mại. |
| Canva Content License Agreement (canva.com/policies/content-license-agreement/) | Free content: được dùng trong template bán. **Pro elements: chỉ bán dưới dạng Canva template link — KHÔNG được xuất file rồi bán.** |
| Quy ước nội bộ (products.md) | KHÔNG Canva Pro elements trong file bán · KHÔNG raw AI output chưa chỉnh sửa · mọi asset phải có commercial license rõ. |

---

## CHECKLIST 5 CỔng (chạy theo thứ tự)

### CỔng 1 — Canva Pro Elements (cổng ĐỎ nhất)

| # | Hạng mục kiểm | Cách kiểm | Bằng chứng cần lưu | Pass / Fail |
|---|---|---|---|---|
| 1.1 | File output (PDF/PNG/Canva link bán) **không chứa bất kỳ element nào có biểu tượng vương miện ♛ (Crown)** trong Canva | Mở file gốc trong Canva → kiểm từng element → xem có icon "Pro" / Crown không | Screenshot toàn bộ canvas + danh sách element dùng | ☐ PASS / ☐ FAIL |
| 1.2 | Nếu dùng Canva Pro element: **chỉ bán dưới dạng Canva template link** (không export file) | Kiểm hình thức giao hàng — link chia sẻ template hay file tải về? | Ghi rõ hình thức giao hàng trong mô tả sản phẩm | ☐ PASS / ☐ N/A |
| 1.3 | Stock photo/illustration từ Canva Pro: xác nhận subscription còn hiệu lực tại thời điểm bán | Đăng nhập Canva → kiểm trạng thái subscription | Ảnh chụp màn hình trạng thái tài khoản Canva | ☐ PASS / ☐ FAIL |

> **Lý do:** Canva Content License Agreement quy định rõ — Pro elements trong file export bán là vi phạm; chỉ được bán Pro content dưới dạng Canva template link. Nếu hủy subscription → mất quyền bán các design đã dùng Pro elements.

---

### CỔng 2 — Raw AI Output

| # | Hạng mục kiểm | Cách kiểm | Bằng chứng cần lưu | Pass / Fail |
|---|---|---|---|---|
| 2.1 | Mọi nội dung AI-generated (văn bản, hình ảnh, code) đều đã qua **chỉnh sửa sáng tạo thực chất của người** (không phải chỉ thay vài từ) | So sánh output AI gốc vs phiên bản cuối — có khác biệt rõ về cấu trúc/nội dung không? | Lưu file AI output gốc + file đã chỉnh (diff) | ☐ PASS / ☐ FAIL |
| 2.2 | Hình ảnh do AI tạo (Midjourney, DALL-E, Stable Diffusion…): kiểm **terms of service của tool đó** có cho phép dùng thương mại không | Đọc ToS của tool AI đã dùng mục "commercial use" | Trích dẫn URL ToS + điều khoản cụ thể | ☐ PASS / ☐ FAIL |
| 2.3 | KHÔNG bán bộ "prompt collection" thuần túy mà chưa có sản phẩm chỉnh sửa thực chất đi kèm | Kiểm nội dung sản phẩm — có phải chỉ là danh sách prompt copy-paste không? | Mô tả rõ giá trị gia tăng của người tạo | ☐ PASS / ☐ FAIL |

> **Lý do:** Theo Luật SHTT VN, tác phẩm được bảo hộ cần có "sự sáng tạo của con người". Raw AI output chưa có tiền lệ pháp lý rõ ràng ở VN → rủi ro tranh chấp + hình ảnh thương hiệu.

### CỔng 3 — Font chữ

| # | Hạng mục kiểm | Cách kiểm | Bằng chứng cần lưu | Pass / Fail |
|---|---|---|---|---|
| 3.1 | Liệt kê TẤT CẢ font dùng trong file | Mở file → kiểm panel font (Canva/Figma/Word) | Danh sách tên font đầy đủ | ☐ PASS / ☐ FAIL |
| 3.2 | Mỗi font: xác nhận license **cho phép commercial use và embedding trong file bán** | Tra license tại trang gốc (Google Fonts = SIL OFL = OK; font mua = kiểm EULA; font system = kiểm EULA OS) | Lưu URL license từng font | ☐ PASS / ☐ FAIL |
| 3.3 | Font có phí thương mại: đã mua license phù hợp | Kiểm email mua license | Lưu receipt/email mua | ☐ PASS / ☐ FAIL |

> **Nguồn tham khảo font an toàn:** Google Fonts (fonts.google.com) — hầu hết SIL Open Font License cho phép thương mại. Font tiếng Việt miễn phí thương mại: Roboto, Montserrat, Be Vietnam Pro, Nunito.

### CỔng 4 — Ảnh, Icon, Nhạc, Vector

| # | Hạng mục kiểm | Cách kiểm | Bằng chứng cần lưu | Pass / Fail |
|---|---|---|---|---|
| 4.1 | Liệt kê tất cả ảnh, icon, vector, nhạc nền (nếu có) | Xem danh sách asset register (xem file 6.2a) | Asset register có đủ cột nguồn + license | ☐ PASS / ☐ FAIL |
| 4.2 | Ảnh stock: từ nguồn **cho phép commercial use** (Unsplash, Pexels, Pixabay — xác nhận từng ảnh; Shutterstock/Adobe Stock nếu có license) | Kiểm license từng ảnh tại URL nguồn | Screenshot license từng ảnh | ☐ PASS / ☐ FAIL |
| 4.3 | Icon/vector: license rõ thương mại (Flaticon — kiểm plan; Font Awesome — kiểm license type; icon tự vẽ = OK) | Kiểm plan/license tại nguồn | URL license | ☐ PASS / ☐ FAIL |
| 4.4 | KHÔNG dùng ảnh/icon lấy từ Google Images/Pinterest mà chưa xác minh license | Kiểm từng asset có nguồn rõ không | Không có asset "lấy từ mạng" vô nguồn | ☐ PASS / ☐ FAIL |
| 4.5 | Canva Free elements (không Crown): OK dùng trong template bán | Đã lọc ở Cổng 1 | (bao gồm trong cổng 1) | ☐ N/A |

### CỔng 5 — Nội dung thông tin (text, data, checklist)

| # | Hạng mục kiểm | Cách kiểm | Bằng chứng cần lưu | Pass / Fail |
|---|---|---|---|---|
| 5.1 | Nội dung văn bản do mình viết hoặc AI + chỉnh sửa thực chất (Cổng 2) | Self-certify | Ghi tên tác giả trong metadata | ☐ PASS / ☐ FAIL |
| 5.2 | Không copy nội dung từ khóa học/sách/tài liệu khác mà chưa có phép | Kiểm xem có đoạn nào paraphrase sát quá từ nguồn nổi tiếng không | Ghi chú nguồn tham khảo nếu có | ☐ PASS / ☐ FAIL |
| 5.3 | Số liệu/thống kê dùng trong sản phẩm: có nguồn trích dẫn hoặc là kinh nghiệm thực tế của founder | Kiểm từng số liệu | Danh sách nguồn trích dẫn | ☐ PASS / ☐ FAIL |
