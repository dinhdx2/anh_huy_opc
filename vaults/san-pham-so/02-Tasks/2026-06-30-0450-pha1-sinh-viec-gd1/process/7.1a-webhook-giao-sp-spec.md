# 7.1a — Spec Luồng Giao Sản Phẩm Tự Động Sau Thanh Toán

**TL;DR:** Spec kỹ thuật đầy đủ cho luồng giao sản phẩm số tự động: cổng tiền webhook → xác thực → cấp link tải (watermark + license key) → email xác nhận → log. Phần cần cổng tiền live đánh dấu [CHỜ 4.1b — NEED-APPROVAL]. Gumroad là lựa chọn 0-dev cho GĐ1.

## 2. Lựa chọn triển khai theo giai đoạn

### Lựa chọn A — Gumroad (Khuyến nghị GĐ1, 0 code)

**Phù hợp:** 0-100 đơn/tháng, không cần dev.

Gumroad tự động xử lý toàn bộ luồng:
1. Thanh toán qua Gumroad checkout
2. Gumroad tự động gửi email giao hàng với link tải
3. PDF Stamping: tự động nhúng email người mua vào PDF
4. License Key: tự động sinh unique key cho mỗi đơn
5. Download limit: đặt trong Dashboard → Product → Content
6. Webhook ra ngoài (nếu cần log thêm): Dashboard → Settings → Advanced → Ping URL

**Setup Gumroad:**
```
1. Tạo tài khoản tại gumroad.com [CHỜ 4.1b — NEED-APPROVAL: đăng ký tài khoản]
2. New Product → Digital Product
3. Tên: "Kit Lên Đơn Đầu Tiên — TikTok Shop & Shopee"
4. Giá: 149,000 VND (hoặc USD tương đương — xem lưu ý VND bên dưới)
5. Upload 5 file kit vào Content
6. Bật: PDF Stamping + License Keys + Download limit (10 lần)
7. Lấy URL product → dùng làm [CHECKOUT_URL] trong landing
```

**Lưu ý VND trên Gumroad:** Gumroad chủ yếu xử lý USD. Nếu muốn thu VND trực tiếp, cần PayOS/Sepay hoặc kết hợp. [cần CEO xác minh phương án VND]

**Phí Gumroad:** 10% mỗi giao dịch (gói free) hoặc $10/tháng (phí thấp hơn). [cần CEO xác minh tại gumroad.com/pricing]

### Lựa chọn B — PayOS (Ưu tiên cho thu VND, cần code đơn giản)

**[CHỜ 4.1b — NEED-APPROVAL]: Cần đăng ký tài khoản PayOS tại payos.vn + xác minh định danh**

**Đặc điểm PayOS:**
- Thu VND trực tiếp qua chuyển khoản ngân hàng / ví điện tử
- Phí: 0% (theo thông tin công khai tại payos.vn tháng 6/2026 — cần CEO xác minh còn áp dụng)
- API webhook đơn giản, có docs tiếng Việt
- Cần backend đơn giản để nhận webhook (Node.js / PHP / Python)

**Cấu hình webhook PayOS:**

```javascript
// Ví dụ handler Node.js (Express) — đặt trên server hoặc Vercel/Netlify Function
const crypto = require('crypto');

// [CHỜ 4.1b]: Thay bằng giá trị thật từ PayOS Dashboard
const PAYOS_CHECKSUM_KEY = process.env.PAYOS_CHECKSUM_KEY; // từ PayOS Dashboard
const PAYOS_API_KEY       = process.env.PAYOS_API_KEY;
const PAYOS_CLIENT_ID     = process.env.PAYOS_CLIENT_ID;

app.post('/webhook/payos', express.json(), (req, res) => {
  const { code, data, signature } = req.body;

  // 1. Xác thực chữ ký
  const rawData = `amount=${data.amount}&cancelUrl=${data.cancelUrl}&description=${data.description}&orderCode=${data.orderCode}&returnUrl=${data.returnUrl}`;
  const expectedSig = crypto.createHmac('sha256', PAYOS_CHECKSUM_KEY)
                             .update(rawData).digest('hex');
  if (expectedSig !== signature) {
    console.error('Webhook signature invalid', { received: signature, expected: expectedSig });
    return res.status(400).json({ error: 'Invalid signature' });
  }

  // 2. Kiểm trạng thái
  if (code !== '00' || data.status !== 'PAID') {
    return res.json({ message: 'Not paid yet' });
  }

  // 3. Kiểm số tiền (chống giả mạo)
  if (data.amount !== 149000) {
    console.error('Amount mismatch', { received: data.amount, expected: 149000 });
    return res.status(400).json({ error: 'Amount mismatch' });
  }

  // 4. Giao hàng (xem hàm deliverProduct bên dưới)
  const orderCode = data.orderCode;
  const buyerInfo = {
    email: data.buyerEmail,    // PayOS truyền nếu khách điền
    name:  data.buyerName,
    phone: data.buyerPhone
  };
  deliverProduct(orderCode, buyerInfo);

  res.json({ success: true });
});
```

## 3. Hàm giao hàng (deliverProduct)

```javascript
// Hàm giao hàng — gọi sau khi xác thực webhook thành công
async function deliverProduct(orderCode, buyerInfo) {
  try {
    // 3a. Sinh license key
    const now = new Date();
    const yyyymm = `${now.getFullYear()}${String(now.getMonth()+1).padStart(2,'0')}`;
    const rand4 = Math.floor(1000 + Math.random() * 9000);
    const initials = (buyerInfo.name || 'XX').slice(0,2).toUpperCase().replace(/\s/g,'');
    const licenseKey = `LDN-${yyyymm}-${rand4}-${initials}`;

    // 3b. Sinh link tải (đơn giản nhất GĐ1: dùng link Google Drive)
    // [CHỜ 4.1b]: Thay bằng link thật sau khi có file kit đã watermark
    // Option thủ công: thêm watermark tay sau mỗi đơn (xem 1.3a)
    // Option Gumroad: bỏ bước này — Gumroad tự giao
    const downloadLink = `[GOOGLE_DRIVE_LINK_HOAC_GUMROAD_LINK]`;

    // 3c. Gửi email giao hàng
    await sendDeliveryEmail({
      to:          buyerInfo.email,
      name:        buyerInfo.name,
      licenseKey:  licenseKey,
      downloadLink: downloadLink,
      orderCode:   orderCode
    });

    // 3d. Ghi log vào Google Sheets (qua API hoặc webhook Zapier)
    await logOrder({
      orderCode,
      name:        buyerInfo.name,
      email:       buyerInfo.email,
      phone:       buyerInfo.phone,
      licenseKey,
      downloadLink,
      deliveredAt: new Date().toISOString(),
      status:      'DELIVERED'
    });

    console.log(`Order ${orderCode} delivered to ${buyerInfo.email}`);
  } catch (err) {
    console.error(`Delivery failed for order ${orderCode}:`, err);
    // Gửi alert đến CEO để giao tay
    notifyCEO(`DELIVERY FAILED: ${orderCode} — ${buyerInfo.email} — ${err.message}`);
  }
}
```

## 5. Xử lý lỗi và giao lại

### Kịch bản lỗi và xử lý

| Lỗi | Phát hiện | Xử lý |
|---|---|---|
| Webhook không nhận được | Cổng tiền retry thường 3-5 lần tự động | Log lỗi server; CEO kiểm dashboard cổng tiền hàng ngày |
| Chữ ký webhook không khớp | `expectedSig !== signature` | Log + alert CEO ngay; KHÔNG giao hàng |
| Gửi email thất bại | Email tool trả lỗi / bounce | Retry 1 lần sau 5 phút; nếu vẫn fail → CEO giao tay |
| Link tải hết hạn | Khách báo link lỗi | Tạo link mới → giao tay qua email (xem SOP 5.2b) |
| Khách không nhận email | Rơi vào spam | Hướng dẫn check spam; giao tay nếu cần |
| Thanh toán thành công nhưng không nhận kit | Dashboard cổng tiền có record nhưng webhook fail | Kiểm log server; CEO giao tay trong 24h |

### Alert CEO (GĐ1 — thủ công)

Khi `deliverProduct()` throw error → gửi email/tin nhắn đến CEO:

```
Subject: [ALERT] Giao hàng thất bại — cần xử lý tay
Nội dung: Order [orderCode] — Khách: [email] — Lỗi: [error message]
Hành động: Tải file kit, watermark tay, gửi email tay theo SOP 5.2b
```
