## 2. Các conversion event cần bắt

### Bảng event — vị trí kích hoạt trong landing

| Event | Khi nào bắn | Vị trí code | Meta event | TikTok event |
|---|---|---|---|---|
| **PageView** | Mỗi khi trang load | `<head>` — tự động | `fbq('track','PageView')` | `ttq.page()` |
| **ViewContent** | Khi trang load xong (window.load) | `<script>` cuối file | `fbq('track','ViewContent',{...})` | `ttq.track('ViewContent')` |
| **Lead** | Khi form opt-in submit thành công | `handleOptinSubmit()` | `fbq('track','Lead')` | `ttq.track('SubmitForm')` |
| **InitiateCheckout** | Khi click nút "Mua Ngay" | `trackPurchaseClick()` | `fbq('track','InitiateCheckout')` | `ttq.track('InitiateCheckout')` |
| **Purchase** | Sau thanh toán thành công | Trang thank-you / webhook | `fbq('track','Purchase',{value:149000,currency:'VND'})` | `ttq.track('CompletePayment',{value:149000,currency:'VND'})` |

## 3. Quy ước UTM (tất cả link ads phải dùng)

### Cấu trúc UTM chuẩn

```
https://[DOMAIN]/[LANDING_PATH]?utm_source=SOURCE&utm_medium=MEDIUM&utm_campaign=CAMPAIGN&utm_content=CONTENT&utm_term=TERM
```

### Bảng quy ước — giá trị từng parameter

| Parameter | Giá trị hợp lệ | Ví dụ |
|---|---|---|
| `utm_source` | `facebook`, `tiktok`, `instagram`, `zalo`, `organic` | `facebook` |
| `utm_medium` | `paid_social`, `cpc`, `video`, `story`, `reel`, `post_organic` | `paid_social` |
| `utm_campaign` | `[tên-chiến-dịch]-[tháng-năm]` — kebab-case, không dấu | `len-don-ra-mat-2026-07` |
| `utm_content` | `[loại-creative]-[angle]-[v{số}]` | `video-angle5-dongcam-v1` |
| `utm_term` | `[nhóm-đối-tượng]` (tùy chọn, dùng cho phân tích sau) | `nha-ban-moi-0-6-thang` |

### Ví dụ URL hoàn chỉnh theo từng kênh

**Facebook/Meta Ads — chiến dịch ra mắt, video angle đồng cảm:**
```
https://[DOMAIN]/?utm_source=facebook&utm_medium=paid_social&utm_campaign=len-don-ra-mat-2026-07&utm_content=video-angle5-dongcam-v1
```

**TikTok Ads — angle tốc độ:**
```
https://[DOMAIN]/?utm_source=tiktok&utm_medium=paid_social&utm_campaign=len-don-ra-mat-2026-07&utm_content=video-angle1-tocdo-v1
```

**TikTok Organic (video tự nhiên):**
```
https://[DOMAIN]/?utm_source=tiktok&utm_medium=post_organic&utm_campaign=len-don-organic-2026-07&utm_content=bio-link-v1
```

**Zalo OA:**
```
https://[DOMAIN]/?utm_source=zalo&utm_medium=oa_message&utm_campaign=len-don-zalo-2026-07&utm_content=welcome-message-v1
```

### Quy tắc đặt tên bắt buộc

1. Tất cả giá trị **chữ thường**, **kebab-case** (dấu gạch ngang thay khoảng trắng), **không dấu tiếng Việt**
2. `utm_campaign` bắt buộc có tháng-năm để phân biệt các đợt
3. `utm_content` bắt buộc có số phiên bản (`v1`, `v2`...) để A/B test
4. KHÔNG dùng ký tự đặc biệt (dấu nháy, dấu %, #)
5. Lưu tất cả URL đã dùng vào Google Sheets để tra cứu

## 4. Map event sang 5 KPI (8.1a-dashboard-5kpi.csv)

| KPI | Dữ liệu cần từ pixel/UTM | Cách lấy | Công thức |
|---|---|---|---|
| **1. CM/ĐƠN** | Số đơn thực tế + chi ads | PayOS/Sepay export + Ads Manager | Giá bán − Phí cổng − (Chi ads / Số đơn) |
| **2. CAC** | Tổng chi ads + Số đơn (Purchase event) | Ads Manager: Amount Spent / Purchases | Chi ads kỳ ÷ Số Purchase event kỳ |
| **3. CR LANDING** | Số Purchase + Tổng PageView | Pixel: Purchase event / PageView count | (Purchase ÷ PageView) × 100% |
| **4. REFUND%** | Số đơn hoàn | PayOS/Sepay + log thủ công | (Đơn refund ÷ Tổng đơn) × 100% |
| **5. SỐ LEAD** | Lead event count | Pixel Lead event + email tool | Đếm Lead event trong kỳ |

### Nguồn dữ liệu theo công cụ

```
[Pixel Meta] → Ads Manager → Reports → Custom → chọn event
[Pixel TikTok] → TikTok Ads Manager → Reports → Conversion
[Email tool] → Dashboard → Subscriber count (mới trong kỳ)
[PayOS/Sepay] → Dashboard → Transactions export
```

## 5. Kiểm thử pixel (cần tài khoản ads thật — đánh dấu chờ live)

### Kiểm Meta Pixel

[CHỜ LIVE — cần tài khoản Meta Business và Pixel ID]

1. Cài extension [Meta Pixel Helper](https://chrome.google.com/webstore/detail/meta-pixel-helper/) trên Chrome
2. Vào landing page → Pixel Helper hiện màu xanh = pixel đang bắn
3. Kiểm từng event: click nút "Mua Ngay" → Pixel Helper hiện `InitiateCheckout`
4. Dùng Test Events trong Events Manager: vào Events Manager → Test Events → paste URL landing → click từng nút → xem event real-time

### Kiểm TikTok Pixel

[CHỜ LIVE — cần tài khoản TikTok Ads và Pixel ID]

1. Cài extension [TikTok Pixel Helper](https://chrome.google.com/webstore/detail/tiktok-pixel-helper/) trên Chrome
2. Tương tự Meta: vào landing → extension hiện event
3. Dùng TikTok Events API Test trong Ads Manager để xác nhận

### Kiểm UTM

Không cần tài khoản ads — kiểm được ngay:
1. Mở landing với UTM: `https://[DOMAIN]/?utm_source=facebook&utm_medium=paid_social&utm_campaign=test`
2. Vào Google Analytics (nếu đã cài) → Realtime → Traffic sources → xem UTM
3. Hoặc kiểm qua [UTM Checker](https://ga-dev-tools.google.com/campaign-url-builder/) để validate format

## 6. Lưu ý tuân thủ

- **Không thu thập dữ liệu cá nhân qua pixel khi chưa có consent** (NĐ 13): Pixel bắn PageView/ViewContent OK vì là dữ liệu hành vi ẩn danh. Pixel bắn Lead/Purchase với email người dùng thì cần có consent từ form (đã có trong landing).
- **iOS 14+ / iOS 17+:** Apple hạn chế tracking — Meta Pixel cần bật Conversions API (server-side) để đo chính xác hơn. [cần CEO xác minh khi đến bước này]
- **TikTok Events API:** tương tự Meta Conversions API, gửi event từ server (sau khi có cổng thanh toán live) để đo chính xác hơn.
