# 1.3b — Quy Trình Giao 1 Đơn Mẫu + Walkthrough Mô Phỏng

> **LƯU Ý QUAN TRỌNG:** Toàn bộ phần dưới đây là **MÔ PHỎNG** — chưa giao thật vì chưa có cổng thanh toán live, chưa có sản phẩm PDF đóng gói hoàn chỉnh, và chưa có hệ thống tự động. Mục đích: thiết kế quy trình để CEO biết sẽ làm gì khi có đơn thật đầu tiên.

**TL;DR:** Walkthrough mô phỏng quy trình giao 1 đơn hoàn chỉnh (thanh toán → watermark → gửi link → log) với các bước thủ công phù hợp GĐ1. Ghi rõ công cụ cần chuẩn bị sẵn. Tiêu chí "giao thành công" được định nghĩa cụ thể.

---

## Tiêu Chí "Giao Thành Công" (định nghĩa trước khi làm)

Một đơn được xem là **giao thành công** khi đủ TẤT CẢ các tiêu chí:

| # | Tiêu chí | Cách kiểm tra |
|---|---|---|
| T1 | Khách đã thanh toán và hệ thống xác nhận | Gumroad/Payhip hiển thị trạng thái "Paid" |
| T2 | Khách nhận được email với link tải trong vòng 15 phút sau thanh toán | Email log từ Gumroad hoặc Gmail gửi thủ công |
| T3 | Link tải hoạt động — khách tải được file | Kiểm bằng cách tự test link trước |
| T4 | File PDF đúng phiên bản, đúng watermark tên người mua | Kiểm file trước khi upload/gửi |
| T5 | Đơn được log vào spreadsheet theo dõi | Kiểm spreadsheet có dòng mới |

### BƯỚC 2 — Tạo file PDF có watermark (10:32 sáng)

**[MÔ PHỎNG] Thực hiện thủ công (phương án không có Gumroad):**

Mở file PDF master → Mở Canva (Free plan):
1. Upload PDF → mở từng trang
2. Thêm text box ở footer: `"Được mua bởi: Nguyễn Thị Lan | [TÊN-BRAND] | Không chia sẻ lại"`
3. Thêm vào trang bìa: `License key: LDN-202607-4821-NT`
4. Export → đặt tên: `hero-kit-nguyen-thi-lan-v1.pdf`

**Thời gian thực tế (mô phỏng):** ~8 phút cho file 6 trang

**[MÔ PHỎNG] Kiểm tra file trước khi gửi:**
- [ ] File đúng tên người mua
- [ ] Watermark xuất hiện ở footer mỗi trang
- [ ] License key ở trang bìa
- [ ] File mở được, text đọc được, không bị lỗi font
- [ ] Dung lượng file hợp lý (<10MB để gửi email)

---

### BƯỚC 3 — Upload file + tạo link tải (10:40 sáng)

**[MÔ PHỎNG]:**

**Dùng Google Drive:**
1. Mở Google Drive → Thư mục "Kit Orders"
2. Upload `hero-kit-nguyen-thi-lan-v1.pdf`
3. Chuột phải → "Get Link" → chọn "Anyone with the link" → Copy link
4. Ghi chú: link này dùng 1 lần cho người này — sau khi gửi xong, đổi setting về "Restricted" để link cũ không hoạt động sau [X] ngày (tùy setup)

**Hoặc dùng Gumroad (tự động):** Gumroad đã tự tạo link → bỏ qua bước này

## Khi Nào Quy Trình Này Không Cần Làm Thủ Công Nữa

- >20 đơn/tháng → đáng setup Gumroad đầy đủ (PDF stamping tự động)
- >100 đơn/tháng → cân nhắc Zapier integration hoặc platform có API (Lemon Squeezy)
- GĐ2+ → có thể thuê VA xử lý đơn thủ công hoặc đầu tư vào hệ thống tự động hóa hoàn toàn
