## Hướng Dẫn Điền Asset Register

### Cột "Loại":
- `text` — văn bản tự soạn
- `image` — ảnh / hình minh họa
- `icon` — biểu tượng
- `font` — font chữ nhúng trong PDF
- `music` — nhạc nền
- `design-template` — template thiết kế

### Cột "License":
- `self-created` — tự tạo 100%
- `canva-free` — Canva Free element (không Crown) — OK bán
- `canva-pro-template-link` — Canva Pro element — chỉ bán dưới dạng Canva template link
- `google-fonts-ofl` — Google Fonts SIL OFL — OK commercial
- `unsplash-free` — Unsplash license — OK commercial không cần ghi nguồn
- `pexels-free` — Pexels license — OK commercial
- `creative-commons-by` — CC BY — cần ghi nguồn
- `purchased` — đã mua license thương mại — cần lưu hóa đơn
- `[tên-license-khác]` — điền rõ

### Cột "Trang_thai":
- `ACTIVE` — đã xác nhận license thương mại, dùng được
- `PENDING` — đang kiểm tra — KHÔNG đưa vào file bán
- `STOP` — không có commercial license — TUYỆT ĐỐI không dùng trong file bán
- `DEPRECATED` — license hết hạn — gỡ khỏi file đang bán

## Quy Trình Khi Thêm Asset Mới

1. Tìm asset từ nguồn trong danh sách "an toàn" ở trên
2. Điền vào bảng Asset Register: STT, Tên, Loại, Nguồn, URL, License
3. Đặt `trang_thai = ACTIVE` (nếu license đã xác nhận) hoặc `PENDING` (đang kiểm)
4. Lưu bằng chứng: screenshot license hoặc URL vào `assets/license-proof/hero-kit-v1/`
5. Chỉ đưa vào file bán khi `trang_thai = ACTIVE`
6. Trước phát hành: xác nhận 0 dòng `STOP` hoặc `PENDING` trong asset register của kit đó
