# 4.1a — Hướng dẫn Deploy Landing Page

**TL;DR:** Hướng dẫn từng bước deploy `4.1a-landing-hero.html` lên hosting miễn phí (Netlify / Vercel / Cloudflare Pages), danh sách placeholder cần thay, checklist go-live, và các phụ thuộc cần CEO duyệt trước khi live.

---

## 1. Tổng quan file

File `4.1a-landing-hero.html` là landing page self-contained — 1 file HTML duy nhất, inline CSS, responsive. Không phụ thuộc framework hay server-side. Deploy bằng cách upload 1 file là xong.

---

## 2. Danh sách placeholder cần thay (bắt buộc trước khi go-live)

Tìm kiếm (Ctrl+F) từng chuỗi sau trong file HTML và thay bằng giá trị thật:

| Placeholder | Mô tả | Nguồn |
|---|---|---|
| `[TÊN-BRAND]` | Tên thương hiệu thật | CEO xác nhận (9.5b) |
| `[CHECKOUT_URL]` | URL trang thanh toán (PayOS / Sepay / Gumroad) | Cần đăng ký cổng tiền trước — **NEED-APPROVAL** |
| `[META_PIXEL_ID]` | ID Meta Pixel (số) | Tài khoản Meta Business — **NEED-APPROVAL** |
| `[TIKTOK_PIXEL_ID]` | ID TikTok Pixel (số) | Tài khoản TikTok Ads — **NEED-APPROVAL** |
| `[PRIVACY_POLICY_URL]` | URL trang Privacy Policy | Đã có mẫu ở `9.2a-privacy-policy.md` — cần deploy lên web |
| `[TERMS_URL]` | URL trang Điều khoản sử dụng | Soạn hoặc bỏ link này nếu chưa có |
| `[DOMAIN]` | Domain thật (vd: kitlendondautien.vn) | CEO đăng ký domain |
| `[EMAIL_HO_TRO]` | Email hỗ trợ khách hàng | CEO xác nhận |
| `[CẦN: điền tên cổng...]` | Tên cổng thanh toán trong FAQ | Điền sau khi chọn cổng |

Sau khi thay xong: tìm kiếm `[CẦN]` và `[TÊN-BRAND]` trong file — nếu còn kết quả thì chưa thay xong.

---

## 3. Bật pixel và email tool (sau khi có tài khoản)

### Bật Meta/TikTok Pixel:
1. Mở file HTML, tìm đoạn comment `<!-- [CẦN]: Meta Pixel -->` và `<!-- [CẦN]: TikTok Pixel -->`
2. Xóa `<!--` và `-->` bao quanh đoạn script (uncomment)
3. Thay `[META_PIXEL_ID]` / `[TIKTOK_PIXEL_ID]` bằng ID thật
4. Uncommment các lệnh `fbq('track',...)` và `ttq.track(...)` trong `<script>` cuối file

### Kết nối form opt-in với email tool:
1. Tạo tài khoản email tool (MailerLite / Brevo / Mailchimp — xem 3.1a)
2. Tạo form trong email tool → lấy embed code hoặc action URL
3. Trong file HTML: tìm `[CẦN EMAIL TOOL]` trong function `handleOptinSubmit()`
4. Thay đoạn placeholder bằng fetch() đến endpoint email tool
5. Kiểm tra double opt-in đã bật (xem 3.1a-form-optin-spec.md)

## 4. Chọn hosting (tất cả miễn phí cho static HTML)

### Lựa chọn A — Netlify (khuyến nghị, đơn giản nhất)

**Cách nhanh nhất (kéo thả — không cần Git):**
1. Vào [netlify.com](https://netlify.com) → Đăng ký tài khoản miễn phí
2. Vào Sites → kéo thả file `4.1a-landing-hero.html` vào vùng deploy
3. Netlify tạo URL random (vd: `https://amazing-tesla-abc123.netlify.app`)
4. Đổi tên site trong Settings nếu muốn subdomain đẹp hơn
5. Thêm custom domain: Settings → Domain management → Add domain → làm theo hướng dẫn

**Giới hạn gói miễn phí:** 100GB bandwidth/tháng — đủ cho GĐ1. Không giới hạn request.

### Lựa chọn B — Vercel

1. Vào [vercel.com](https://vercel.com) → Đăng ký bằng GitHub/GitLab/Bitbucket
2. Import project hoặc dùng Vercel CLI: `npx vercel --prod`
3. Tương tự Netlify về tính năng, cũng miễn phí

### Lựa chọn C — Cloudflare Pages

1. Vào [pages.cloudflare.com](https://pages.cloudflare.com) → Đăng ký tài khoản
2. Tạo project → Upload → kéo thả file HTML
3. Ưu điểm: CDN Cloudflare toàn cầu, tốc độ tải nhanh

### Lựa chọn D — Landing builder (nếu muốn editor kéo thả)

Nếu không muốn tự chỉnh HTML, có thể dùng:
- **Carrd.co** — $19/năm cho custom domain, giao diện drag-drop đơn giản
- **Gamma.app** — có landing page builder AI, gói free có quảng cáo
- **Trang.io** (VN) — landing builder VN, giá [cần CEO xác minh]

Trong trường hợp này, copy nội dung từ file HTML vào builder theo từng section.

## 5. Checklist go-live (tất cả phải PASS trước khi chạy ads)

### Nội dung & Pháp lý
- [ ] Tất cả placeholder `[...]` đã được thay bằng giá trị thật
- [ ] Tìm kiếm `[CẦN]` trong file — kết quả = 0
- [ ] Privacy Policy (9.2a) đã online và URL hoạt động
- [ ] Link Privacy Policy trong form opt-in mở đúng trang
- [ ] Checkbox consent KHÔNG tích sẵn khi vào trang
- [ ] Form không submit được khi chưa tích checkbox

### Kỹ thuật
- [ ] Trang load được trên Chrome (desktop + mobile)
- [ ] Trang load được trên Safari iPhone
- [ ] Nút "Mua Ngay" dẫn đúng đến trang checkout
- [ ] Form opt-in submit → nhận email xác nhận trong 5 phút [CAN EMAIL TOOL]
- [ ] Pixel bắn đúng event PageView khi vào trang [CAN PIXEL]
- [ ] Event ViewContent bắn khi trang load xong [CAN PIXEL]
- [ ] Google Analytics (hoặc tương đương) đang ghi traffic [tùy chọn]

### Cổng thanh toán (NEED-APPROVAL — chờ CEO đăng ký)
- [ ] PayOS / Sepay / Gumroad đã đăng ký và xác minh tài khoản
- [ ] Sản phẩm đã tạo trên cổng thanh toán với đúng giá 149.000đ
- [ ] URL checkout đã thay vào `[CHECKOUT_URL]`
- [ ] Test thanh toán thành công (dùng tài khoản test của cổng)
- [ ] Email giao hàng được gửi sau khi thanh toán thành công (xem 7.1a)

### Tracking & Đo
- [ ] UTM parameter hoạt động (xem 8.2a-tracking-pixel-utm-spec.md)
- [ ] Dashboard 5 KPI (8.1a) có nguồn dữ liệu từ landing
- [ ] Đo CR landing = Đơn / Lượt vào trang (mục tiêu >1%, tốt >2%)
